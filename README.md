# 上海大鲨鱼 CBA 日历

上海久事大鲨鱼 **2026–2027 赛季**比赛日历，支持赛程变化后自动同步。

**[打开订阅页面](https://jemonking.github.io/cba_calendar/)**

订阅地址：`https://jemonking.github.io/cba_calendar/shanghai-sharks.ics`

## iPhone / iPad

在订阅页面点击「订阅到 Apple 日历」；或打开 **日历 → 日历 → 添加日历 → 添加订阅日历**，粘贴上述地址。

**请订阅，不要下载 .ics 文件后导入。** 导入只会增加普通日程，不会自动更新，也不能一键取消。

取消订阅：日历 → 找到「上海大鲨鱼」日历 → ⓘ →「取消订阅」。已导入到其他日历的比赛不会随之删除。

## 赛程与更新

- 包含 CBA 常规赛及官方公布后的季后赛；不含季前赛、俱乐部杯和全明星赛。
- 以 [CBA 官方公开赛程](https://www.cbaleague.com/)为准，每天北京时间 **10:23、18:23** 通过 GitHub Actions 检查更新。
- 比赛使用稳定 UID；官方改期会更新原事件。抓取失败时保留上次成功版本。
- Apple 日历的刷新时间由客户端决定，并非实时推送。

非官方球迷项目，与 CBA 或上海久事俱乐部无隶属关系。
